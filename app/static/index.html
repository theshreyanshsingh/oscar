    Connect Oscar to WhatsApp

    Run this in a terminal, in the Oscar folder:

    .venv-whatsapp/bin/python -m app.whatsapp

    First time? Follow the WhatsApp setup in the README.

    Heads up: this is an unofficial WhatsApp Web connection. It breaks WhatsApp's terms, and WhatsApp can ban the number, so give Oscar a spare number, never your own.

    Connecting to WhatsApp…

    This box updates on its own. The details are shown above.

    1. Grab the phone that has Oscar's spare number, not your own phone. Whichever WhatsApp account scans the code becomes Oscar.
    2. Open WhatsApp → Settings → Linked devices → Link a device.
    3. Scan this code. A new one replaces it every 20 to 60 seconds, for up to an hour.
